# Stock Trading Game

A stock trading survival game built with Phaser 3 + TypeScript.

## Gameplay

- Watch the real-time candlestick (K-line) chart
- Buy and sell stocks at the right moment
- Survive as long as possible — game over when total assets drop below $100

## Features

- **Candlestick chart** with auto-scrolling and price grid
- **7 preset scenarios**: rally, crash, sideways, V-reversal, inverted V-reversal, slow climb, slow decline
- **5-second tick** per candle
- **All-in / All-out** trading

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
