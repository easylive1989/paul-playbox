# 保羅的遊樂場 - Paul's Playbox

遊戲是第九藝術，喜歡遊戲，熱愛遊戲，持續追尋創意。

## 遊戲列表

| 遊戲 | 技術 | 路徑 |
|------|------|------|
| Flutter Breakout | Flutter | `/flutter_breakout/` |
| Flutter Tetris | Flutter | `/flutter_tetris/` |
| Player NS Shaft | Flutter | `/player_ns_shaft/` |
| Ray World Game | Flutter | `/ray_world_game/` |
| Water Sort Puzzle | Flutter | `/water_sort_puzzle/` |
| Tiny Swords RTS | JavaScript | `/tiny_swords/` |
| Water Bottle Flip | Phaser 3 | `/water_bottle_flip/` |
| Stock Trading | JavaScript | `/stock_trading_game/` |
| Sokoban | JavaScript | `/sokoban/` |

## 技術棧

- **Flutter** - 大部分遊戲使用 Flutter 開發，編譯為 Web 版本
- **JavaScript** - Tiny Swords RTS、Sokoban、Stock Trading 使用原生 JS 開發
- **Phaser 3** - Water Bottle Flip 使用 Phaser 3 引擎
